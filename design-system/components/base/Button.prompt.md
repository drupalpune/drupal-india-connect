The system's only button. Radius 6px, weight 700, 2px border, 0.2s colour transitions.

```jsx
<Button label="Get event updates" href="#notify" variant="primary" size="large" />
<Button label="Plan to speak" variant="secondary-inverted" icon="arrow-right" />
```

Variants: `primary` (blue fill), `secondary` (pale sky fill, dark text), `primary-inverted` (white fill, blue text — for use on navy/orange bands), `secondary-inverted` (transparent with a blue outline). One primary per view; everything else is secondary or outlined.

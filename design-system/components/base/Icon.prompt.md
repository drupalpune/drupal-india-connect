Renders one glyph from the system's fixed 18-icon Phosphor set, inheriting `currentColor`.

```jsx
<Icon icon="calendar" size="medium" />
```

The set is closed: arrow-right/left, caret-right/left, download, user-plus, rocket, play-circle, pause-circle, star, check, x, calendar, search, mail, phone, map-pin, external-link. If a design needs a glyph that is not here, add it to the theme's `icon.twig` map first — do not inline a one-off SVG.

The closing ask on a page — newsletter, tickets, sponsorship. Minimum 20rem tall with generous block padding, so it reads as a deliberate stop.

```jsx
<Cta headingText="Be first to know" text="Venue, CFP and early-bird tickets, announced to the list first." backgroundColor="secondary"
  actions={<Button label="Keep me posted" variant="primary-inverted" size="large" />} />
```

One CTA band per page. `secondary` (orange) is the house choice for the newsletter; `inverted` for a quieter sponsorship ask.

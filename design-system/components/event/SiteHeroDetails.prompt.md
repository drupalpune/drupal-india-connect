The rotated date/location tab that hangs off the homepage hero, with a calendar button opening a per-day programme flyout.

```jsx
<SiteHeroDetails dates="18–20 January 2027" location="Asia — city TBA" days={[{ label: 'Day one', info: 'Sessions' }]} />
```

Rotated −90° and absolutely positioned above 700px; a normal inline strip below that. It is rendered by `SiteHero25` — you rarely place it yourself.

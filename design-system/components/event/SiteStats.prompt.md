The dark full-bleed stats band that sits directly under the homepage hero. Figures at 56px/800 on navy, with the label column pushed right on wide screens.

```jsx
<SiteStats title="Highlights from 2026" stats={[{ stat: '800', desc: 'Attendees' }, { stat: '60', desc: 'Sessions' }]} />
```

Real numbers only, and normally last year's — a first-edition event should omit this band rather than project figures.
